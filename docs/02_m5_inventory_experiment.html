方法论说明

本 Notebook 使用 M5 公开销量数据，但：

  • M5 不含真实库存、缺货、补货或供应商提前期。
  • 本 Notebook 中的供应商提前期、初始库存、持有/缺货成本全部是模拟假设。
  • 结果仅适用于这些假设，不代表 Walmart 或京东的真实业务结论。
  • 这是公开数据上的方法适配，不是对论文京东实验的复现。

M5 销量与合成供应提前期：端到端补货方法的可复现实验 Goal 用公开的 Walmart M5 日销量，搭建一个可在 Google Colab 重跑的学习型复现实验：比较直接按库存成本训练的神经策略（E2E）、条件近邻分位数策略（PTO1）和点预测加正态分位数策略（PTO2），再把它们放进按周检查、含在途订单的多周期库存模拟器中比较。 这是公开数据上的方法适配，不是论文京东实验的复现。M5 不含库存、缺货、补货或供应商提前期；本 notebook 会模拟提前期和初始库存，并把销量作为需求代理。结果只适用于这些假设，不能解释成 Walmart 或京东的真实业务结论。 Context & Methods 每个补货决策使用过去 28 天销量、合成供应商特征和当前库存位置。提前期由可观测特征 z1、z2 和决策时不可见的扰动 ξ 产生：

  • z1、z2 独立取 1–4；ξ 取 −1、0、1，概率各为 1/3；L=max(1,z1+z2+ξ)。
  • 每 7 天检查一次库存。订单在 L 天后到达；下单时只看 z1、z2，不知道 ξ。
  • 每日成本为 h×库存 + b×欠交量；设 h=0.1、b=0.9，单周期临界分位数 α=b/(b+h)=0.9。

    • 对比方法：

  • E2E-DL：MLP 直接输出订单量，用训练样本上的可微库存仿真成本训练。
  • PTO1-kNN：在训练样本中找相似需求历史与供应商特征，估计保护期累计需求的经验 α 分位数。
  • PTO2-Ridge+Normal：岭回归预测保护期累计需求均值，再用残差标准差和正态分位数得到目标库存。

    • PTO1/PTO2 是可解释基准，不是作者实现的逐行复刻。E2E 也采用教学用 MLP 和单周期成本目标；最终验证会放入多周期补货模拟器。 Key Assumptions

  1. M5 销量近似需求。若真实库存曾约束销售，该代理会低估潜在需求。
  2. M5 没有库存与供应商数据。提前期、初始库存及持有/缺货成本都是模拟假设。
  3. 不计订货固定成本、采购成本、价格变化、替代品、报废和供应商容量限制。
  4. 训练、验证、测试按时间先后分开；比较方法使用同一抽样、测试日期、提前期场景和初始库存。
  5. 训练样本是独立周期；最终测试则是重复补货模拟。这一差异是重要局限。

Data 数据来源：M5 数据集的 Zenodo 开放镜像，DOI 10.5281/zenodo.10203108。本文只下载历史销量文件（约 120 MB），包含商品×门店序列和 d_1–d_1913 日销量。 先下载并校验 MD5，再按门店均衡抽取少量商品序列，以控制 Colab 内存和运行时间。

def md5_file(path, chunk_size=1024 * 1024):
    digest = hashlib.md5()
    with open(path, "rb") as handle:
        for chunk in iter(lambda: handle.read(chunk_size), b""):
            digest.update(chunk)
    return digest.hexdigest()

if not SALES_PATH.exists() or md5_file(SALES_PATH) != EXPECTED_MD5:
    temporary_path = SALES_PATH.with_suffix(".download")
    if temporary_path.exists():

    print("Downloading the M5 sales file from Zenodo...")

Methods: prepare chronological decision episodes An origin is the number of sales days observed when a replenishment decision is made. The target is cumulative sales over the realized lead time plus the 7-day review interval. The model receives z1 and z2 but not random shock ξ. The split leaves at least one maximum protection horizon between train, validation and test origins. Demand lags are normalized by the recent 28-day mean; that scale is also a feature.

def make_demand_features(history, z1, z2):
    scale = np.maximum(history.mean(axis=1), MIN_SCALE).astype(np.float32)
    lags = history[:, ::-1] / scale[:, None]
    lead_features = np.column_stack([
        z1 / 4.0,
        z2 / 4.0,
        (z1 + z2) / 8.0,
    ]).astype(np.float32)
    features = np.column_stack([lags, np.log1p(scale), lead_features]).astype(np.float32)
    return features, scale

def make_episode_set(origins, series_indices, seed):
    rng = np.random.default_rng(seed)
    demand_features, policy_features = [], []
    future_paths, lead_times, horizons = [], [], []
    inventory_positions, scales, targets, episode_series, episode_origins = [], [], [], [], []

    for origin in origins:
        history = sales[series_indices, origin - LOOKBACK:origin]
        n_series = len(series_indices)
        z1 = rng.integers(1, 5, size=n_series)
        z2 = rng.integers(1, 5, size=n_series)
        xi = rng.choice(np.array([-1, 0, 1]), size=n_series, p=[1/3, 1/3, 1/3])
        lead = np.maximum(1, z1 + z2 + xi)
        horizon = lead + REVIEW_DAYS
        x_demand, scale = make_demand_features(history, z1, z2)

        inventory_ratio = rng.uniform(-1.0, 8.0, size=n_series).astype(np.float32)
        x_policy = np.column_stack([x_demand, inventory_ratio]).astype(np.float32)
        future = sales[series_indices, origin:origin + MAX_HORIZON].copy()
        future_normalized = future / scale[:, None]
        target = np.array([
            future_normalized[row, :horizon[row]].sum()
            for row in range(n_series)
        ], dtype=np.float32)

        demand_features.append(x_demand)
        policy_features.append(x_policy)
        future_paths.append(future_normalized.astype(np.float32))
        lead_times.append(lead.astype(np.int64))
        horizons.append(horizon.astype(np.int64))
        inventory_positions.append(inventory_ratio)
        scales.append(scale)
        targets.append(target)
        episode_series.append(series_indices.copy())
        episode_origins.append(np.full(n_series, origin, dtype=np.int32))

    return {
        "demand_X": np.vstack(demand_features),
        "policy_X": np.vstack(policy_features),
        "future": np.vstack(future_paths),
        "lead": np.concatenate(lead_times),
        "horizon": np.concatenate(horizons),
        "inventory_ratio": np.concatenate(inventory_positions),
        "scale": np.concatenate(scales),
        "target": np.concatenate(targets),
        "series_index": np.concatenate(episode_series),
        "origin": np.concatenate(episode_origins),
    }

def fit_standardizer(values):
    mean = values.mean(axis=0)
    scale = values.std(axis=0)
    scale[scale < 1e-6] = 1.0
    return mean.astype(np.float32), scale.astype(np.float32)

def apply_standardizer(values, mean, scale):
    return ((values - mean) / scale).astype(np.float32)

def numpy_cycle_cost(order_quantity, initial_position, future, lead, horizon):
    order_quantity = np.asarray(order_quantity, dtype=np.float64)
    on_hand = np.maximum(np.asarray(initial_position, dtype=np.float64), 0.0)
    backlog = np.maximum(-np.asarray(initial_position, dtype=np.float64), 0.0)
    costs = np.zeros(len(order_quantity), dtype=np.float64)
    for day in range(1, MAX_HORIZON + 1):
        on_hand += order_quantity * (lead + 1 == day)
        backlog_fulfilled = np.minimum(on_hand, backlog)
        on_hand -= backlog_fulfilled
        backlog -= backlog_fulfilled
        active = horizon >= day
        demand_today = future[:, day - 1] * active
        demand_fulfilled = np.minimum(on_hand, demand_today)
        on_hand -= demand_fulfilled
        backlog += demand_today - demand_fulfilled
        costs += active * (HOLD_COST * on_hand + SHORTAGE_COST * backlog)
    return costs

def knn_quantile_predictions(query_demand_z, k, batch_size=256):
    train_norm2 = np.sum(train_demand_z ** 2, axis=1)
    predictions = []
    for start in range(0, len(query_demand_z), batch_size):
        query = query_demand_z[start:start + batch_size]
        distances = (
            np.sum(query ** 2, axis=1, keepdims=True)
            + train_norm2[None, :]
            - 2.0 * query @ train_demand_z.T
        )
        np.maximum(distances, 0.0, out=distances)
        neighbor_idx = np.argpartition(distances, kth=k - 1, axis=1)[:, :k]
        predictions.append(np.quantile(train["target"][neighbor_idx], CRITICAL_RATIO, axis=1))
    return np.concatenate(predictions).astype(np.float32)

RIDGE_ALPHA = 10.0
train_design = np.column_stack([np.ones(len(train_demand_z)), train_demand_z])
penalty = np.eye(train_design.shape[1], dtype=np.float64) * RIDGE_ALPHA
penalty[0, 0] = 0.0
ridge_coef = np.linalg.solve(
    train_design.T @ train_design + penalty,
    train_design.T @ train["target"].astype(np.float64)
)
ridge_train_mean = train_design @ ridge_coef
ridge_residual_sd = float(np.sqrt(np.mean((train["target"] - ridge_train_mean) ** 2)))

def ridge_mean_prediction(demand_z):
    design = np.column_stack([np.ones(len(demand_z)), demand_z])
    return (design @ ridge_coef).astype(np.float32)

def pto2_target(demand_z):
    mean_prediction = ridge_mean_prediction(demand_z)
    return np.maximum(0.0, mean_prediction + NORMAL_Z90 * ridge_residual_sd)

Train and select the policies The E2E MLP sees demand and supplier features plus current inventory position. For each training example, its predicted order is inserted into a differentiable lead-time/review-period inventory cycle. The loss accumulates daily holding and backlog costs. Validation cycle cost selects the stopping epoch. PTO1's neighbor count is selected on validation cost. PTO2 uses a fixed ridge penalty and one residual standard deviation; this global normal approximation is intentionally easy to inspect.

import torch.nn as nn

def torch_cycle_cost(order_quantity, initial_position, future, lead, horizon):
    on_hand = torch.clamp(initial_position, min=0.0)
    backlog = torch.clamp(-initial_position, min=0.0)
    total_cost = torch.zeros_like(order_quantity)
    for day in range(1, MAX_HORIZON + 1):
        arrival_mask = (lead + 1 == day).to(order_quantity.dtype)
        on_hand = on_hand + order_quantity * arrival_mask
        backlog_fulfilled = torch.minimum(on_hand, backlog)
        on_hand = on_hand - backlog_fulfilled
        backlog = backlog - backlog_fulfilled
        active = (horizon >= day).to(order_quantity.dtype)
        demand_today = future[:, day - 1] * active
        demand_fulfilled = torch.minimum(on_hand, demand_today)
        on_hand = on_hand - demand_fulfilled
        backlog = backlog + demand_today - demand_fulfilled
        total_cost = total_cost + active * (HOLD_COST * on_hand + SHORTAGE_COST * backlog)
    return total_cost

class DirectOrderMLP(nn.Module):
    def __init__(self, n_features):
        super().__init__()
        self.network = nn.Sequential(
            nn.Linear(n_features, 64), nn.ReLU(),
            nn.Linear(64, 32), nn.ReLU(),
            nn.Linear(32, 1), nn.Softplus(),
        )
    def forward(self, x):
        return self.network(x).squeeze(-1)

model = DirectOrderMLP(train_policy_z.shape[1]).to(DEVICE)
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3, weight_decay=1e-5)

        batch_idx = order[start:start + BATCH_SIZE]
        predicted_order = model(train_tensors["x"][batch_idx])

            train_tensors["future"][batch_idx], train_tensors["lead"][batch_idx],

        validation_order = model(validation_tensors["x"])

            validation_order, validation_tensors["inventory"],
            validation_tensors["future"], validation_tensors["lead"],
            validation_tensors["horizon"]

        validation_score = float(
            (validation_cycle_cost * validation_tensors["scale"]).mean().cpu()

    if validation_score < best_validation_cost - 1e-6:
        best_validation_cost = validation_score
        best_epoch = epoch
        best_state = {name: value.detach().cpu().clone() for name, value in model.state_dict().items()}
        stale_epochs = 0
    else:
        stale_epochs += 1
    if epoch == 1 or epoch % 10 == 0:
        print(f"epoch {epoch:3d} | validation weighted cycle cost {validation_score:.3f}")
    if stale_epochs >= patience:

Multi-period inventory evaluation The final comparison places orders every 7 days over the later holdout. At each day's start, arrivals first clear old backlog; then the policy may order; daily M5 sales consume available stock, and unmet demand becomes backlog. The policy sees only past sales, z1/z2 and current inventory position (on-hand − backlog + pipeline). All policies replay the same simulated supplier scenarios and starting inventory. Results include cost, same-day fill rate, backlog and order size so that a cost improvement cannot hide a service trade-off.

def make_simulation_scenarios(n_series, n_reviews, seed):
    rng = np.random.default_rng(seed)
    z1 = rng.integers(1, 5, size=(n_reviews, n_series))
    z2 = rng.integers(1, 5, size=(n_reviews, n_series))
    xi = rng.choice(np.array([-1, 0, 1]), size=(n_reviews, n_series), p=[1/3, 1/3, 1/3])
    lead = np.maximum(1, z1 + z2 + xi)
    initial_days = rng.uniform(0.0, 5.0, size=n_series)
    return z1, z2, lead, initial_days

def simulate_inventory_policy(policy_name, series_indices, z1_scenarios, z2_scenarios,
                              lead_scenarios, initial_days):
    n_series = len(series_indices)
    review_days = list(range(SIM_START_ORIGIN, SIM_END_ORIGIN_EXCLUSIVE, REVIEW_DAYS))
    assert len(review_days) == z1_scenarios.shape[0]

    initial_history = sales[series_indices, SIM_START_ORIGIN - LOOKBACK:SIM_START_ORIGIN]
    initial_scale = np.maximum(initial_history.mean(axis=1), MIN_SCALE)
    on_hand = initial_days * initial_scale
    backlog = np.zeros(n_series, dtype=np.float64)
    pipeline_position = np.zeros(n_series, dtype=np.float64)
    arrival_book = {}
    trace_cost, trace_inventory, trace_backlog, trace_backlog_share = [], [], [], []
    total_demand, same_day_fulfilled, total_order_quantity = 0.0, 0.0, 0.0
    review_number = 0

    for day_index in range(SIM_START_ORIGIN, SIM_END_ORIGIN_EXCLUSIVE):
        arriving = arrival_book.pop(day_index, np.zeros(n_series, dtype=np.float64))
        pipeline_position -= arriving
        on_hand += arriving
        old_backlog_fulfilled = np.minimum(on_hand, backlog)
        on_hand -= old_backlog_fulfilled
        backlog -= old_backlog_fulfilled

        if (day_index - SIM_START_ORIGIN) % REVIEW_DAYS == 0:
            z1, z2 = z1_scenarios[review_number], z2_scenarios[review_number]
            actual_lead = lead_scenarios[review_number]
            inventory_position = on_hand - backlog + pipeline_position
            history = sales[series_indices, day_index - LOOKBACK:day_index]
            demand_x, scale = make_demand_features(history, z1, z2)

            if policy_name == "E2E-DL":
                policy_x = np.column_stack([demand_x, inventory_position / scale]).astype(np.float32)
                order_quantity = predict_e2e_order(policy_x) * scale
            elif policy_name == "PTO1-kNN":
                demand_z = apply_standardizer(demand_x, demand_mean, demand_sd)
                target_level = knn_quantile_predictions(demand_z, selected_k)
                order_quantity = np.maximum(0.0, target_level - inventory_position / scale) * scale
            elif policy_name == "PTO2-Ridge+Normal":
                demand_z = apply_standardizer(demand_x, demand_mean, demand_sd)
                target_level = pto2_target(demand_z)
                order_quantity = np.maximum(0.0, target_level - inventory_position / scale) * scale
            else:
                raise ValueError(f"Unknown policy: {policy_name}")

            for lead_value in np.unique(actual_lead):
                mask = actual_lead == lead_value
                arrival_day = day_index + int(lead_value)
                if arrival_day not in arrival_book:
                    arrival_book[arrival_day] = np.zeros(n_series, dtype=np.float64)
                arrival_book[arrival_day][mask] += order_quantity[mask]
            pipeline_position += order_quantity
            total_order_quantity += float(order_quantity.sum())
            review_number += 1

        demand_today = sales[series_indices, day_index].astype(np.float64)
        total_demand += float(demand_today.sum())
        served_today = np.minimum(on_hand, demand_today)
        on_hand -= served_today
        backlog += demand_today - served_today
        same_day_fulfilled += float(served_today.sum())

        daily_cost = HOLD_COST * on_hand + SHORTAGE_COST * backlog
        trace_cost.append(float(daily_cost.mean()))
        trace_inventory.append(float(on_hand.mean()))
        trace_backlog.append(float(backlog.mean()))
        trace_backlog_share.append(float(np.mean(backlog > 1e-8)))

    n_days = SIM_END_ORIGIN_EXCLUSIVE - SIM_START_ORIGIN
    metrics = {
        "Policy": policy_name,
        "Mean cost per series-day": float(np.sum(trace_cost) / n_days),
        "Same-day fill rate": same_day_fulfilled / max(total_demand, 1.0),
        "Backlog-positive series-day share": float(np.mean(trace_backlog_share)),
        "Mean on-hand units": float(np.mean(trace_inventory)),
        "Mean backlog units": float(np.mean(trace_backlog)),
        "Mean order quantity (units/order)": total_order_quantity / (review_number * n_series),
    }
    return metrics, {
        "cost": np.array(trace_cost),
        "inventory": np.array(trace_inventory),
        "backlog": np.array(trace_backlog),
    }

English Version — M5 Inventory Experiment

This notebook uses public Walmart M5 sales as a demand proxy to compare an end-to-end neural policy (E2E-DL), a KNN quantile policy (PTO1), and a ridge-regression/normal-quantile policy (PTO2) in a multi-period inventory simulator.

M5 provides sales, not latent demand, inventory, stockouts, replenishments, or supplier lead times. Lead times, initial stock, and holding/stockout costs are therefore simulated assumptions. The notebook is a methodological extension, not a replication of the paper’s JD.com field experiment or a claim about Walmart’s real operations.

With seed 2025, the simulated mean cost per series-day is PTO1-kNN 1.6686, E2E-DL 1.8402, and PTO2-Ridge+Normal 4.8404. PTO1 has the lowest cost under this particular simulation; the result depends on the assumed demand proxy, lead-time scenarios, initial inventory, and cost ratio. It cannot establish which policy performs best in real operations.
