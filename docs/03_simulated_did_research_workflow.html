模拟 DID：从识别假设到稳健性诊断

模拟 DID：从识别假设到稳健性诊断

Goal

练习把一项库存管理政策评估组织成可审计的因果研究：先算四格 DID，再用单位与时间固定效应估计，检查事件研究的干预前趋势，并做一个仅使用干预前数据的 placebo。

本 notebook 完全使用人为生成的面板数据。真实处理效应被设为 −5，目的是检查分析流程能否找回已知答案；这不是论文的京东估计，也不提供任何实际业务证据。

Context & Methods

模拟 40 个门店、24 期数据，20 个门店从第 12 期开始采用政策。结果变量是库存成本指数，真实政策效应为 −5。模型为：

Y_it = α_i + λ_t + β(Treated_i × Post_t) + ε_it

  • α_i 控制不随时间变化的门店差异。
  • λ_t 控制所有门店共同经历的时间冲击。
  • 标准误按门店聚类，以容许同一门店内的误差随时间相关。
  • DID 的因果解释依赖平行趋势、无提前反应、无跨门店溢出和没有同时发生的差异化政策冲击。

事件研究与 placebo 是诊断工具，不能证明平行趋势成立。

Steps 1–2: generate the controlled panel

先固定随机种子，再生成门店固定差异、共同时间冲击和门店内自相关误差。政策只影响处理组的干预后期，真实效应已知为 −5。

import numpy as np
import pandas as pd

try:
    import matplotlib.pyplot as plt
    HAS_MATPLOTLIB = True
except ImportError:
    HAS_MATPLOTLIB = False
    print("Matplotlib unavailable; numerical analysis will run, figures are skipped.")

SEED = 2042
rng = np.random.default_rng(SEED)
N_UNITS = 40
N_PERIODS = 24
TREATMENT_START = 12
TRUE_EFFECT = -5.0
N_TREATED = 20

treated_units = set(rng.choice(N_UNITS, size=N_TREATED, replace=False).tolist())
unit_effects = rng.normal(loc=0.0, scale=8.0, size=N_UNITS)
common_shocks = rng.normal(loc=0.0, scale=0.8, size=N_PERIODS)
time_effects = 0.25 * np.arange(N_PERIODS) + 1.5 * np.sin(np.arange(N_PERIODS) / 3) + common_shocks

records = []
for unit in range(N_UNITS):
    treated = int(unit in treated_units)
    serial_error = np.zeros(N_PERIODS)
    innovations = rng.normal(loc=0.0, scale=1.5, size=N_PERIODS)
    for period in range(N_PERIODS):
        serial_error[period] = innovations[period] if period == 0 else 0.55 * serial_error[period - 1] + innovations[period]
        post = int(period >= TREATMENT_START)
        did = treated * post
        outcome = unit_effects[unit] + time_effects[period] + TRUE_EFFECT * did + serial_error[period]
        records.append({
            "unit": unit,
            "period": period,
            "treated": treated,
            "post": post,
            "did": did,
            "outcome": outcome,
        })

panel = pd.DataFrame(records)
print("Panel rows:", len(panel))
print("Units:", panel["unit"].nunique(), "| periods:", panel["period"].nunique())
print("Treated units:", panel.loc[panel["treated"] == 1, "unit"].nunique())
print("Policy starts at period:", TREATMENT_START)

Step 3: calculate the four-cell DID

The arithmetic estimate is the change in treated units minus the change in controls. This is the most transparent first check and gives the coefficient the fixed-effects regression should recover in this balanced panel.

Step 4: two-way fixed effects with clustered uncertainty

Treatment status is absorbed by unit fixed effects, and the post indicator is absorbed by time fixed effects. The coefficient of interest is the treated×post interaction. We calculate a CR1 cluster-robust covariance matrix by summing score contributions at the unit level.

In [3]
def fit_clustered_ols(frame, outcome_name, focal_terms, cluster_name="unit"):
    unit_dummies = pd.get_dummies(frame["unit"], prefix="unit", drop_first=True, dtype=float).to_numpy()
    time_dummies = pd.get_dummies(frame["period"], prefix="time", drop_first=True, dtype=float).to_numpy()
    focal = frame[focal_terms].to_numpy(dtype=float)
    x = np.column_stack([np.ones(len(frame)), focal, unit_dummies, time_dummies])
    y = frame[outcome_name].to_numpy(dtype=float)

    xtx_inverse = np.linalg.pinv(x.T @ x)
    beta = xtx_inverse @ x.T @ y
    residual = y - x @ beta

    unique_clusters = frame[cluster_name].unique()
    meat = np.zeros((x.shape[1], x.shape[1]), dtype=float)
    for cluster in unique_clusters:
        mask = frame[cluster_name].to_numpy() == cluster
        score = x[mask].T @ residual[mask]
        meat += np.outer(score, score)

    n_obs, n_parameters = x.shape
    n_clusters = len(unique_clusters)
    correction = (n_clusters / (n_clusters - 1)) * ((n_obs - 1) / (n_obs - n_parameters))
    covariance = correction * xtx_inverse @ meat @ xtx_inverse
    standard_errors = np.sqrt(np.maximum(np.diag(covariance), 0.0))
    return {
        "beta": beta,
        "se": standard_errors,
        "cov": covariance,
        "n_clusters": n_clusters,
        "n_obs": n_obs,
        "n_parameters": n_parameters,
    }

did_fit = fit_clustered_ols(panel, "outcome", ["did"])
did_estimate = did_fit["beta"][1]
did_se = did_fit["se"][1]
T_CRITICAL_39 = 2.0227  # two-sided 95% critical value for t with 39 degrees of freedom
did_ci = (did_estimate - T_CRITICAL_39 * did_se, did_estimate + T_CRITICAL_39 * did_se)

print(f"TWFE DID estimate: {did_estimate:.3f}")
print(f"Unit-clustered SE: {did_se:.3f} (clusters={did_fit['n_clusters']})")
print(f"Approximate 95% cluster-t CI: [{did_ci[0]:.3f}, {did_ci[1]:.3f}]")
print(f"Known simulated effect: {TRUE_EFFECT:.3f}")
print("Arithmetic and TWFE estimates match:", np.isclose(did_estimate, did_four_cell, atol=1e-9))

Step 5: event-study pre-trend diagnostic

We omit event month −1 as the reference period and estimate treatment-group interactions for event months −8 through −2 and 0 through 11. Pre-policy coefficients should fluctuate around zero in this data-generating process. A noisy plot is a diagnostic; failure to reject a pre-trend is not proof that parallel trends holds.

Step 6: placebo using only pre-policy periods

A fake intervention at period 6 is tested after dropping every actual post-policy observation. Since no treatment effect exists in the retained data, the placebo estimate should be near zero. This checks the mechanics and can expose obvious pre-policy differences, but a favorable placebo result does not establish the identifying assumptions.

In [5]
pre_policy = panel.loc[panel["period"] < TREATMENT_START].copy()
pre_policy["fake_post"] = (pre_policy["period"] >= 6).astype(int)
pre_policy["fake_did"] = pre_policy["treated"] * pre_policy["fake_post"]
placebo_fit = fit_clustered_ols(pre_policy, "outcome", ["fake_did"])

Checks & research interpretation

  • The four-cell DID and two-way fixed-effects coefficient should match in this balanced panel.
  • The estimated policy effect should be reasonably close to the known −5, with uncertainty reflecting unit-level clustering.
  • Inspect pre-policy event-study estimates and the pre-only placebo.
  • State the treatment timing, control group, outcome, unit of analysis, and clustering level before interpreting any real estimate.
  • In an applied study, also investigate treatment selection, spillovers, simultaneous interventions, missing outcomes, alternative controls and sensitivity to the event window.

The simulation has deliberately favorable parallel trends. Real applications do not reveal the counterfactual. Pre-trend plots, placebo outcomes and robustness checks support scrutiny but cannot prove the DID assumptions.

English Version — Simulated Difference-in-Differences Workflow

This notebook demonstrates how to organize a causal analysis of an inventory policy: calculate the four-cell DID, estimate a two-way fixed-effects model, inspect an event study, and run a placebo using only pre-policy data. All observations are artificially generated. The known treatment effect is −5; the simulation is not an estimate of the paper’s JD.com effect or evidence about a real business.

The panel contains 40 stores over 24 periods; 20 stores receive the policy from period 12. The outcome is a simulated inventory-cost index. The model is Y_it = α_i + λ_t + β(Treated_i × Post_t) + ε_it. Standard errors are clustered by store to allow within-store serial correlation. Causal interpretation in real applications requires assumptions including parallel trends, no anticipation, no spillovers, and no concurrent differential shocks. Event studies and placebo tests are diagnostics, not proof of these assumptions.

The four-cell DID and two-way fixed-effects estimate are both −4.300. The store-clustered standard error is 0.356 and the approximate 95% confidence interval is [−5.021, −3.580], compared with the known simulated effect of −5.000. The pre-policy placebo estimate is −0.827 with an approximate 95% interval [−1.865, 0.211]. The simulation uses deliberately favorable parallel trends; real applications do not reveal the counterfactual.
