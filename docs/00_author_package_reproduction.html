作者 ZIP 数据包：复现审计

结论：ZIP 足以重新计算若干已提供样本上的作者分析结果，但不足以精确重现论文报告的全部实验结果。本文明确区分“复算 ZIP 样本”和“精确复现论文”。

1. ZIP 中有什么

已检查你提供的作者复现包及其原始 README。主要内容包括：

  • df_test.csv：3,000 个 SKU 的随机抽样离线测试数据，文件内包含作者模型/基准的决策或预测输出。README 说明完整原始数据规模过大，未全部发布。
  • 四个实验 CSV：处理组和对照组各 500 对 SKU/DC 的实验前、实验后样本。
  • control_demand_vlt.csv：用于构造候选对照组的需求和供应商提前期变量。
  • 三个作者 Notebook：离线 E2E 分析、现场实验汇总、倾向得分匹配。
  • 少量脱敏示例数据：每日销售、一个月库存和供应商提前期示例。

在该 ZIP 中没有找到完整模型训练代码、全量运营记录或所有已训练模型权重。因此，Notebook 中的部分模型结果来自已提供的预测/决策字段，不能从原始训练流程重新生成。

单位沿用论文和作者 Notebook 的成本单位。你提供的论文 PDF（第 7–8 页）说明 Figure 2 使用食品与零食类别的 24,333 个 SKU；ZIP README 则说明 df_test.csv 是 3,000 个 SKU 的随机子样本。由于样本、模型输入/输出和完整训练材料不齐，不能把左、右两列当成同一全量实验的完全一致结果，也不能仅凭这些差值推断具体原因。

不能声称：我们精确复现了论文 Figure 2 的全量数值或作者模型训练。

3. 现场实验：500 对抽样数据与论文 Table 2

你提供的论文 PDF Table 2 报告实验后平均总成本为处理组 1,094.54、对照组 1,837.47；论文第 7 页说明现场实验包含 61,430 个订单、9,308 个 SKU，处理组和对照组各使用 6,097 对 SKU/DC。作者 README 说明 ZIP 中现场实验文件只是每组 500 对 SKU/DC 的随机子样本。用这些文件重新汇总得到的实验后总成本为处理组 884.09、对照组 1,985.15。它们不等于论文全量表格结果。

此外，重新运行作者 DID 汇总 Notebook 后，个别 DID 检验统计量与 Notebook 文件内保存的输出存在差异。因此，不能把当前样本汇总描述为论文现场实验的精确统计复现。

4. 为什么目前不能完成“全文精确复现”

  1. 关键离线文件是 3,000-SKU 抽样数据，而论文报告的是 24,333-SKU 实验。
  2. 现场实验文件是每组 500 对 SKU/DC 的抽样数据，不是论文完整实验记录。
  3. ZIP 未提供完整训练样本、完整训练代码和所有模型权重；有些模型预测已经作为字段提供。
  4. 重新运行现场实验 Notebook 时，个别 DID 检验统计量与保存输出不同，尚不能据此确认逐项完全一致。

要完成论文层面的精确复现，至少还需要与论文版本对应的完整分析输入、模型训练实现/权重、确定性随机种子及完整评估流程。如果作者/期刊不提供这些材料，准确的研究结论应是“基于公开抽样包的部分复算”，并明确报告不可复现的部分。

5. 其余项目页面的定位

附录 B 合成实验、M5 库存扩展和模拟 DID 页面用于练习方法和研究工作流程。它们不是作者 ZIP 上的论文结果复现，也不能替代精确复现。M5 未提供真实库存与供应商提前期，所以相应变量为模拟设定；模拟 DID 的真实处理效应是人为设定的。

Author ZIP Package: Replication Audit

Conclusion: The ZIP is sufficient to recompute some author analyses on the supplied samples, but it is insufficient to reproduce every reported experiment in the paper exactly. This report separates “recomputing the ZIP sample” from “exactly reproducing the paper.”

1. What the ZIP contains

We inspected the author package you supplied and its original README. Its main contents are:

  • df_test.csv: a random 3,000-SKU offline test sample containing author-model and benchmark decisions or predictions. The README says the complete original dataset was too large to release.
  • Four field-experiment CSV files: pre- and post-period samples of 500 SKU/DC pairs each for treatment and control.
  • control_demand_vlt.csv: demand and vendor-lead-time variables for candidate controls.
  • Three author notebooks: offline E2E analysis, field-experiment summary, and propensity-score matching.
  • Small anonymized examples for daily sales, one month of inventory, and vendor lead time.

The ZIP does not contain the complete model-training code, full operational records, or all trained model weights. Some model results are therefore read from supplied prediction/decision fields rather than regenerated from the original training pipeline.

Accurate claim: We reran the authors’ original analysis notebook on the available 3,000-SKU ZIP file and reproduced that notebook’s saved output for this sample.
Unsupported claim: We exactly reproduced the full-sample values in paper Figure 2 or the authors’ model training.

3. Field experiment: sampled 500 pairs versus paper Table 2

Table 2 in the supplied article PDF reports post-period mean total costs of 1,094.54 for treatment and 1,837.47 for control. Page 7 says the field experiment involved 61,430 orders and 9,308 SKUs, with 6,097 SKU/DC pairs in each of the treatment and control groups. The author README describes the ZIP field-experiment files as random samples of 500 SKU/DC pairs per group. Re-aggregating those files gives post-period total costs of 884.09 for treatment and 1,985.15 for control. These do not equal the paper’s full-experiment table.

In addition, after rerunning the authors’ DID-summary notebook, some DID test statistics differ from the outputs saved in the notebook file. The current sample summary therefore cannot be described as an exact statistical reproduction of the paper’s field experiment.

4. Why an exact reproduction of the whole paper is not yet possible

  1. The key offline file is a 3,000-SKU sample, while the paper reports an experiment on 24,333 SKUs.
  2. The field-experiment files sample 500 SKU/DC pairs per group rather than providing all records used in the paper.
  3. The ZIP lacks full training samples, complete training code, and all model weights; some model predictions are supplied as data fields.
  4. When the field-experiment notebook is rerun, some DID test statistics differ from its saved outputs, so item-by-item exact agreement is not established.

An exact reproduction at the paper level would require the complete analysis inputs corresponding to the published version, the model-training implementation and weights, deterministic random seeds, and the full evaluation pipeline. If the authors or journal do not provide these materials, the accurate conclusion is “partial recalculation using the public sample package,” with unreproducible parts explicitly documented.

5. How to interpret the other project pages

The Appendix B synthetic exercise, M5 inventory extension, and simulated DID page are for learning methods and research workflow. They are not reproductions of the paper’s results using the author ZIP and cannot substitute for exact reproduction. M5 does not provide real inventory or supplier lead times, so those variables are simulated; the simulated DID uses an artificially assigned true treatment effect.
