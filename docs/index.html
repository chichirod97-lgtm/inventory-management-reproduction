End-to-End Inventory Management: A Learning Reproduction

This project studies A Practical End-to-End Inventory Management Model with Deep Learning and publishes bilingual HTML reports for a synthetic experiment, an M5-based methodological extension, and a DID workflow demonstration. These materials are for learning methods and do not claim an exact reproduction of every result in the paper.
