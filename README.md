# 端到端库存管理：中英双语 HTML 作业 / End-to-End Inventory Management: Bilingual HTML Submission

本公开仓库发布论文学习型复现项目的中英双语 HTML 报告。报告包括附录 B 风格合成实验、基于公开 M5 销量的库存策略扩展，以及模拟 DID 研究流程。它们用于方法学习，不构成对论文全部实证结果的精确复现，也不代表真实业务效果。

This public repository hosts the Chinese-English HTML reports for a learning-oriented reproduction project. The reports cover an Appendix B-inspired synthetic experiment, an inventory-policy extension using public M5 sales, and a simulated DID research workflow. They are intended for learning methods; they do not claim an exact reproduction of every empirical result in the paper or estimate real business effects.

## 复现范围 / Scope

M5 报告中库存、交期及成本相关变量采用明确标注的模拟设定；M5 原始销量为公开数据。模拟 DID 报告是流程演示。作者提供的原始复现数据包和源 Notebook 未放入本公开仓库；仓库内 HTML 报告说明了结果、假设与限制。

The M5 report uses explicitly labeled simulated assumptions for inventory, lead times, and costs; the underlying M5 sales data are public. The simulated DID report demonstrates a workflow. The authors’ original replication data package and source notebooks are not included in this public repository; the HTML reports describe their results, assumptions, and limitations.

The original article is *A Practical End-to-End Inventory Management Model with Deep Learning*.
